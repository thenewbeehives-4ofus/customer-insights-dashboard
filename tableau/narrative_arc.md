# Narrative Arc

The dashboard answers one question: **where should retention effort focus?**

## View Order

1. **Overview (with annotations)** — top-line trend, callouts to the inflection points that motivate the rest of the dashboard.
2. **Segment drill-down** — RFM segments compared side-by-side: which segments are growing, which are decaying.
3. **Trend with trendline** — for the highest-leverage segment, a longitudinal view with fitted trendline making the trajectory unambiguous.

Each view answers a follow-up question raised by the previous view, so a viewer reading top-to-bottom builds a coherent story rather than browsing disconnected charts.
